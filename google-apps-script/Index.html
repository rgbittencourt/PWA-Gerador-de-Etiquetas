Destino do QR Code

Defina para onde cada etiqueta deve apontar. Deixe em branco para o QR conter apenas o código do patrimônio como texto simples.

Placeholders disponíveis: {CODIGO} · {NOME} · {CATEGORIA} · {LOCAL} · {ORIGEM}. Use o link do Mapa de Armários, de uma planilha, ou qualquer URL — o que for colocado aqui é reproduzido literalmente, apenas substituindo os placeholders.

Opções de impressão

Escolha o modelo de folha, quantas cópias gerar, a partir de qual posição começar e quais campos aparecem em cada etiqueta.

Define a sequência das etiquetas na folha. "Ordem de seleção" mantém a ordem em que você marcou os itens; as demais reorganizam tudo em ordem alfabética pelo campo escolhido — útil para conferir mais rápido durante a colagem.

Gera mais de uma etiqueta idêntica para o mesmo item (backup, mais de um local, etc.).

Use para aproveitar uma folha parcialmente usada — pula as posições anteriores em branco.

Quanto maior a correção, mais o QR resiste a sujeira, riscos ou dobras sem falhar na leitura — mas o desenho fica mais denso, o que pode dificultar a leitura em etiquetas muito pequenas. M atende bem a maioria dos casos.

Código e Nome sempre aparecem. Nem todo campo cabe em etiquetas pequenas (ex: 6180) — teste antes de imprimir tudo.

Se a impressora desalinhar um pouco, corrija aqui (positivo = direita/baixo) em vez de refazer a folha inteira.

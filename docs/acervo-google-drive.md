# Acervo oficial no Google Drive

Esta página integra ao repositório o acervo complementar mantido em `1. Projetos`. O código versionado permanece no GitHub; o Drive preserva os manuais ilustrados, capturas, recursos gráficos e o pack completo para recuperação em outra máquina.

## Recursos visuais

A pasta contém os ícones oficiais (512 px e 192 px), ícone Apple Touch, favicon e, quando disponível, imagem de compartilhamento. As cópias utilizadas pela aplicação também ficam versionadas no diretório público deste repositório.

## Política de versionamento

- GitHub: código-fonte, configurações de exemplo e documentação de desenvolvimento.
- Google Drive: documentação operacional ilustrada, arquivos editáveis, capturas e pack de recuperação.
- ZIPs não são duplicados no GitHub para evitar binários redundantes e divergência entre versões.

# Gerador de Etiquetas INOVALAB

PWA público do Gerador de Etiquetas com QR Code do INOVALAB.

## Conteúdo

- `google-apps-script/`: backend e interface originais.
- `app/`: aplicação pública que incorpora a interface original e consulta o Apps Script.
- `public/`: manifesto, favicon, ícones e recursos de compartilhamento.

## Validação

```bash
pnpm test
```
